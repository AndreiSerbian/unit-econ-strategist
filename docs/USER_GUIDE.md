# Руководство пользователя

## Введение

"Стратегический Анализ" - это комплексная платформа для анализа юнит-экономики вашего бизнеса. Это руководство поможет вам максимально эффективно использовать все возможности приложения.

## Быстрый старт

### 1. Регистрация
1. Перейдите на главную страницу
2. Нажмите "Вход" в правом верхнем углу
3. Перейдите на вкладку "Регистрация"
4. Введите email и пароль
5. Нажмите "Зарегистрироваться"

### 2. Создание первого проекта
1. После входа вы автоматически попадете в дашборд
2. Выберите валюту для вашего бизнеса
3. Начните заполнять основные показатели

### 3. Базовый анализ
1. Заполните показатели в разделе "Показатели"
2. Система автоматически рассчитает CAC, CPL, точку безубыточности
3. Просмотрите графики и визуализации

## Разделы приложения

### 📊 Показатели

Основной раздел для работы с метриками вашего бизнеса.

#### Выбор валюты
В верхней части страницы выберите валюту:
- RUB (₽) - Российский рубль
- USD ($) - Доллар США
- EUR (€) - Евро
- MDL (L) - Молдавский лей

#### Основные показатели бизнеса

**Текущая ситуация**
Заполните актуальные данные за последний период:
- **Выручка** - общий доход компании
- **Выручка от постоянных клиентов** - доход от существующей клиентской базы
- **Средний чек постоянных клиентов** - средняя сумма покупки
- **Количество постоянных клиентов**
- **Выручка от новых клиентов** - доход от маркетинга
- **Средний чек новых клиентов**
- **Количество новых клиентов**
- **Количество лидов** - потенциальных клиентов

**Сценарий А (Пессимистичный)**
Смоделируйте ситуацию при ухудшении показателей:
- Снижение продаж на 20-50%
- Уменьшение конверсии
- Рост расходов

**Сценарий Б (Оптимистичный)**
Смоделируйте ситуацию при улучшении:
- Рост продаж в 1.5-2 раза
- Увеличение конверсии
- Оптимизация расходов

#### Детальная структура расходов

**Постоянные расходы (Fixed Costs)**
Расходы, не зависящие от объема продаж:
- Зарплата отдела продаж (постоянная часть)
- Аренда офиса/склада
- Оклады руководства
- Коммунальные услуги
- Связь и интернет

**Переменные расходы (Variable Costs)**

*Маркетинг*:
- Закупка трафика (контекстная реклама, таргет)
- Оплата подрядчиков
- CRM-системы

*Фонд оплаты труда*:
- Бонусы менеджерам за продажи
- Комиссионные

*Производство/Исполнение*:
- Материалы и сырье
- Логистика
- Процент партнерам
- Ремонт оборудования

*Другие расходы*:
- Налоги (укажите ставку в %)
- Прочие переменные затраты

#### Добавление пользовательских категорий

В каждом разделе расходов можно добавить свои категории:
1. Нажмите "+" в нужном разделе
2. Введите название категории
3. Укажите сумму
4. Категория появится в списке

#### Синхронизация с продуктами

Если у вас заполнены продукты:
1. Нажмите кнопку "Синхронизировать с продуктами"
2. Выручка и расходы автоматически подтянутся из продуктовой матрицы

#### Ключевые метрики

После заполнения данных система автоматически рассчитает:

**CAC (Customer Acquisition Cost)** - стоимость привлечения клиента
```
CAC = (Маркетинг + Бонусы продажникам) / Количество новых клиентов
```

**CPL (Cost Per Lead)** - стоимость лида
```
CPL = Маркетинговые расходы / Количество лидов
```

**Точка безубыточности** - количество клиентов для окупаемости
```
Breakeven = Постоянные расходы / (Средний чек - Переменные на клиента)
```

**Прибыль на оплату** - прибыль с одного клиента

**Маржа** - процент прибыли от выручки

#### Сравнение сценариев

В разделе появляются графики:
- Сравнение ключевых метрик
- ROI по сценариям
- Чувствительность к изменениям
- Структура расходов

### 📦 Продукты

Управление продуктовым портфелем компании.

#### Добавление продукта
1. Нажмите "Добавить продукт"
2. Заполните поля:
   - **Название** - наименование продукта/услуги
   - **Цена** - цена продажи
   - **Себестоимость** - затраты на производство
   - **Количество** - объем продаж за период
3. Нажмите "Сохранить"

#### Редактирование продукта
1. Нажмите на карточку продукта
2. Измените нужные поля
3. Сохраните изменения

#### Удаление продукта
Нажмите на иконку корзины на карточке продукта

#### Графики продуктов
- **Выручка по продуктам** - pie chart распределения выручки
- **Прибыль по продуктам** - bar chart маржинальности
- **Объемы продаж** - количество проданных единиц

#### Сравнение с конкурентами
Если у конкурентов добавлены продукты, появляется:
- Сравнение средних цен
- Сравнение объемов продаж
- Распределение по каналам сбыта

### 👥 Конкуренты

Конкурентный анализ и бенчмаркинг.

#### Добавление конкурента
1. Нажмите "Добавить конкурента"
2. Укажите название компании
3. Заполните базовые метрики (опционально):
   - Выручка
   - Доля рынка
   - Качество (оценка 1-10)
   - Маркетинговые расходы

#### Детальный анализ конкурента
Для каждого конкурента можно заполнить:
- Полную структуру расходов (как для своей компании)
- Продуктовый портфель
- SWOT-анализ

#### Продукты конкурентов
1. Откройте карточку конкурента
2. Перейдите в раздел "Продукты"
3. Добавьте продукты конкурента:
   - Название
   - Цена
   - Годовой объем продаж
   - Канал сбыта (онлайн/офлайн/оба)

#### SWOT-анализ

Проведите SWOT-анализ для своей компании и конкурентов:

**Сильные стороны (Strengths)**
- Преимущества и сильные активы
- То, что делаете лучше конкурентов

**Слабые стороны (Weaknesses)**
- Недостатки и уязвимости
- Области для улучшения

**Возможности (Opportunities)**
- Рыночные тренды
- Потенциал роста
- Новые ниши

**Угрозы (Threats)**
- Риски и вызовы
- Действия конкурентов
- Изменения рынка

Для каждой категории:
1. Введите пункт в текстовое поле
2. Нажмите Enter или кнопку "+"
3. Пункт добавится в список
4. Удалите ненужные пункты крестиком
5. Нажмите "Сохранить SWOT анализ"

#### Сравнительные графики
- Сравнение ключевых метрик
- ROI компании vs конкуренты
- Конкурентный индекс
- Структура расходов

### 📈 Аналитика

Продвинутые инструменты анализа и прогнозирования.

#### История изменений метрик

**Сохранение снимка**
1. Заполните актуальные метрики в разделе "Показатели"
2. Перейдите в "Аналитика"
3. Нажмите "Сохранить снимок"
4. Текущие значения сохранятся с датой

**Просмотр истории**
- Выберите метрику для отображения (выручка, прибыль, CAC и т.д.)
- График покажет динамику изменений
- Наведите на точки для деталей

**Лучшие практики**:
- Сохраняйте снимки регулярно (еженедельно/ежемесячно)
- Минимум 2 снимка нужны для прогнозирования
- Больше данных = точнее прогнозы

#### Прогнозирование метрик

**Как работает**:
Система использует линейную регрессию для прогноза на основе исторических данных:
- Анализирует тренд изменений
- Рассчитывает 95% доверительный интервал
- Показывает верхнюю и нижнюю границы прогноза

**Использование**:
1. Выберите метрику для прогноза
2. Выберите период (1, 3, 6 или 12 месяцев)
3. График покажет:
   - Исторические данные (сплошная линия)
   - Прогноз (пунктир)
   - Доверительный интервал (заштрихованная область)

**Интерпретация**:
- Если тренд растущий → метрика будет улучшаться
- Если падающий → нужны меры для исправления
- Широкий интервал → высокая неопределенность
- Узкий интервал → стабильные показатели

#### Резюме сценариев

**Ручное заполнение**:
1. Выберите сценарий (Текущий, А или Б)
2. Заполните поле "Общее резюме":
   - Ключевые выводы
   - Что работает хорошо
   - Проблемные зоны
3. Заполните "Рекомендации":
   - Конкретные действия
   - Приоритеты
   - Ожидаемый эффект

**Автоматическая генерация**:
1. Нажмите кнопку "Сгенерировать" у поля рекомендаций
2. Система проанализирует метрики и создаст рекомендации:
   - Для отрицательной маржи - срочные меры
   - Для высокого CAC - оптимизация каналов
   - Для точки безубыточности - необходимые действия

#### План действий

**Добавление задачи вручную**:
1. Нажмите "Добавить"
2. Заполните:
   - **Название** - краткое описание задачи
   - **Описание** - детали и контекст
   - **Приоритет** - высокий/средний/низкий
   - **Срок** - дата выполнения
3. Нажмите "Добавить"

**Генерация рекомендаций**:
1. Нажмите "Генерировать"
2. Система создаст задачи на основе метрик:
   - Если маржа < 10% → оптимизация расходов
   - Если CAC > 1000 → пересмотр маркетинга
   - Если не достигнута безубыточность → увеличение чека

**Управление задачами**:
- Меняйте статус: В ожидании → В работе → Выполнено
- Удаляйте ненужные задачи
- Отслеживайте прогресс

**Приоритизация**:
- 🔴 Высокий - критично для бизнеса
- 🟡 Средний - важно, но не срочно
- 🟢 Низкий - можно отложить

### 🎮 Теория игр

Матрица платежей для стратегических решений.

#### Как использовать
1. Выберите свою стратегию (строка)
2. Выберите стратегию конкурента (столбец)
3. Ячейка покажет результат (ваш выигрыш, выигрыш конкурента)

#### Интерпретация
- Зеленые ячейки - выгодный исход
- Красные ячейки - невыгодный исход
- Ищите равновесие Нэша - взаимовыгодную позицию

И предлагает:
- Приоритетные направления развития

## Советы по эффективному использованию

### 📌 Регулярность обновления данных
- Обновляйте метрики минимум раз в месяц
- Сохраняйте снимки для отслеживания динамики
- Пересматривайте сценарии ежеквартально

### 📌 Точность данных
- Используйте реальные данные из бухгалтерии
- Разделяйте постоянные и переменные расходы корректно
- Учитывайте все категории затрат

### 📌 Сценарное планирование
- Сценарий А - реалистичный пессимизм (не катастрофа)
- Сценарий Б - достижимый оптимизм (не фантазия)
- Разрыв между сценариями не должен быть > 2х

### 📌 Конкурентный анализ
- Добавьте 3-5 ключевых конкурентов
- Обновляйте их данные по мере получения информации
- Фокусируйтесь на прямых конкурентах

### 📌 SWOT-анализ
- Будьте честны в оценке слабостей
- Ищите возможности в изменениях рынка
- Обновляйте SWOT при значительных изменениях

### 📌 Прогнозирование
- Нужно минимум 4-5 снимков для точного прогноза
- Учитывайте сезонность бизнеса
- Корректируйте прогнозы при изменении условий

## Частые вопросы (FAQ)

**В: Как удалить проект?**
О: В текущей версии удаление проекта не реализовано. Обратитесь в поддержку.

**В: Можно ли работать без регистрации?**
О: Да, но данные будут храниться только локально в браузере и потеряются при очистке кеша.

**В: Сколько конкурентов можно добавить?**
О: Неограниченное количество, но рекомендуем фокусироваться на 3-5 ключевых.

**В: Как изменить валюту проекта?**
О: Выберите нужную валюту в селекторе вверху раздела "Показатели".

**В: Почему не генерируются рекомендации?**
О: Для генерации рекомендаций нужны заполненные детальные расходы и ключевые метрики.

**В: Как интерпретировать точку безубыточности?**
О: Это количество клиентов, которое нужно обслужить, чтобы покрыть все расходы. Если вы выше этой точки - бизнес прибыльный.

**В: Что делать, если CAC слишком высокий?**
О: 
1. Оптимизируйте маркетинговые каналы
2. Улучшите конверсию лендингов
3. Работайте с удержанием клиентов (LTV)
4. Тестируйте более дешевые каналы привлечения

**В: Как часто обновлять прогнозы?**
О: Ежемесячно добавляйте новые снимки метрик. Прогнозы будут автоматически пересчитываться.
