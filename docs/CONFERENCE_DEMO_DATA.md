# Conference Demo Data — Unit Economics Prototype

This document provides realistic sample data for live demonstrations of the
Unit Economics prototype at the academic conference. It is **manual input
only** — no seed button. Choose ONE scenario (E-commerce or SaaS), enter the
data sequentially, and follow the demo narrative.

Recommended demo path (no broken or unfinished actions):

> **Моя компания → Показатели → Cash Flow → Итоги → Теория**

## Demo narrative (suggested 6–8 minutes)

1. **Моя компания (1.5 мин)** — показать ввод продуктов и расходов;
   подчеркнуть, что вкладка предназначена ТОЛЬКО для ввода (input-first).
2. **Показатели (2 мин)** — derived analytics: revenue, profit, CAC, LTV,
   LTV/CAC, payback. Объяснить причинно-следственную связь:
   *products → revenue → margin*; *lead sources → CAC*; *LTV inputs → LTV*.
3. **Cash Flow (1.5 мин)** — таймлайн на 12 месяцев, NPV, окупаемость.
   Упомянуть: «редактирование строк будет в будущей версии» (видна
   подсказка). Inline-редактирование ячеек работает.
4. **Итоги (2 мин)** — четыре сводные карточки: Компания → Cash Flow →
   Риски → Рекомендации. Затем сравнение сценариев и AI-аналитика.
5. **Теория (1 мин)** — game theory matrix и стратегический словарь как
   академическое обрамление работы.

## What NOT to demo live

- Холодный старт (пустой проект) — некоторые карточки покажут
  «Недостаточно данных».
- Редактирование строк Cash Flow — кнопка намеренно отключена.
- Глубокая работа с вкладкой «Конкуренты» в одиночку — без перехода в
  «Рынок» большая часть сравнительной аналитики не видна.

## Subjective vs computed

Везде, где аналитика опирается на оценочные данные пользователя
(конкуренты, SWOT, качество, рыночные оценки), отображается badge
«Субъективная экспертная оценка». Внутренние метрики (CAC, LTV, маржа,
прибыль, выручка, Cash Flow, сценарии) такого badge не имеют — это
чистые расчёты по формулам.
