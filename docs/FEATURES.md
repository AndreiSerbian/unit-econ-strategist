# Описание функций и возможностей

## Обзор функционала

Платформа "Стратегический Анализ" предоставляет полный набор инструментов для анализа юнит-экономики бизнеса и конкурентной стратегии.

## 1. Управление проектами

### Создание проекта
- Автоматическое создание при первом входе
- Привязка к пользователю
- Персистентное хранилище в Supabase

### Настройки проекта
- Выбор валюты (RUB, USD, EUR, MDL)
- Название и описание
- Метаданные (дата создания, обновления)

## 2. Анализ показателей компании

### Базовые метрики
**Входные данные**:
- Выручка (общая, от постоянных и новых клиентов)
- Средний чек (для разных сегментов)
- Количество клиентов (всего, новые, постоянные)
- Количество лидов
- Конверсия

**Рассчитываемые метрики**:
- CAC (Customer Acquisition Cost)
- CPL (Cost Per Lead)
- LTV (Lifetime Value) - планируется
- Точка безубыточности
- Прибыль на клиента
- Маржинальность (%)

### Детальная структура расходов

**Постоянные расходы (Fixed Costs)**:
```
├── Зарплата отдела продаж
│   ├── По старым клиентам
│   └── По новым клиентам
├── Административные расходы
│   ├── Аренда офиса
│   ├── Аренда склада
│   ├── Зарплата руководства
│   ├── Зарплата отдела маркетинга
│   └── Зарплата производственного персонала
├── Коммунальные услуги
│   ├── Интернет
│   ├── Связь
│   ├── Уборка
│   └── Прочие
└── Пользовательские категории (неограниченно)
```

**Переменные расходы (Variable Costs)**:
```
├── Маркетинг
│   ├── Закупка трафика
│   ├── Оплата подрядчиков
│   ├── CRM и сервисы
│   └── Пользовательские категории
├── Фонд оплаты труда (переменная часть)
│   ├── Бонусы по старым клиентам
│   ├── Бонусы по новым клиентам
│   └── Пользовательские категории
├── Производство/Исполнение
│   ├── Материалы
│   ├── Кураторы/исполнители
│   ├── Логистика
│   ├── Процент партнерам
│   ├── Ремонт оборудования
│   └── Пользовательские категории
└── Другие переменные расходы
    ├── Налоги (с настройкой ставки %)
    └── Пользовательские категории
```

### Сценарное планирование
- **Текущая ситуация** - актуальное состояние бизнеса
- **Сценарий А** - пессимистичный прогноз (спад)
- **Сценарий Б** - оптимистичный прогноз (рост)

Для каждого сценария:
- Независимые входные данные
- Автоматический пересчет всех метрик
- Визуальное сравнение

## 3. Управление продуктами

### Продукты компании
**Атрибуты**:
- Название
- Цена продажи
- Себестоимость
- Количество продаж
- Автоматический расчет выручки и прибыли

**Возможности**:
- Неограниченное количество продуктов
- CRUD операции (Create, Read, Update, Delete)
- Синхронизация с основными метриками
- Расчет маржинальности по продуктам

### Продукты конкурентов
**Атрибуты**:
- Название
- Цена
- Годовой объем продаж
- Канал сбыта (онлайн/офлайн/оба)

**Анализ**:
- Сравнение цен с вашими продуктами
- Анализ объемов продаж
- Распределение по каналам сбыта

## 4. Конкурентный анализ

### Профили конкурентов
**Базовая информация**:
- Название компании
- Выручка
- Доля рынка (%)
- Оценка качества (1-10)
- Маркетинговые расходы

### Детальный анализ конкурентов
**Полная юнит-экономика**:
- Клиентская база (всего, новые, постоянные)
- Средний чек
- Конверсия
- Детальная структура расходов (как у своей компании)
- Расчет CAC, CPL, маржи

**Возможности**:
- Неограниченное количество конкурентов
- Полный паритет метрик с основной компанией
- Сравнительный анализ

### SWOT-анализ

**Для каждой компании (своей и конкурентов)**:
- ✅ Strengths (Сильные стороны)
- ⚠️ Weaknesses (Слабые стороны)
- 🎯 Opportunities (Возможности)
- 🚨 Threats (Угрозы)

**Функционал**:
- Добавление неограниченного количества пунктов в каждую категорию
- Редактирование и удаление пунктов
- Сохранение в базу данных
- Табличное представление по компаниям

### Конкурентный индекс
**Рассчитывается на основе**:
- Качество продукции/услуг
- Ценовая политика
- Доля рынка
- Эффективность маркетинга
- ROI

**Визуализация**:
- Радарная диаграмма
- Рейтинг компаний
- Слабые/сильные стороны

## 6. Резюме и рекомендации

### Резюме по сценариям
**Для каждого сценария**:
- Текстовое резюме (произвольное)
- Рекомендации по улучшению
- История изменений

**Автогенерация рекомендаций**:

- CAC (высокий/нормальный)
- Точку безубыточности (достигнута/нет)

Генерирует:
- Приоритетные действия
- Конкретные шаги
- Ожидаемый эффект

## 7. История и прогнозирование

### История изменений метрик
**Функционал**:
- Сохранение снимков метрик с датой
- Хранение для каждого сценария отдельно
- Визуализация на графиках

**Отслеживаемые метрики**:
- Выручка
- Прибыль
- CAC
- CPL
- Маржа (%)
- Точка безубыточности

**Возможности**:
- Выбор метрики для отображения
- График динамики во времени
- Подробная информация по каждой точке

### Прогнозирование метрик
**Метод**: Линейная регрессия

**Возможности**:
- Прогноз на 1, 3, 6, 12 месяцев
- 95% доверительный интервал
- Визуализация верхней и нижней границ

**Требования**:
- Минимум 2 исторических снимка
- Больше снимков = точнее прогноз

**Отображение**:
- Исторические данные (сплошная линия)
- Прогноз (пунктирная линия)
- Доверительный интервал (заштрихованная область)

## 8. План действий

### Управление задачами
**Атрибуты задачи**:
- Название
- Описание
- Приоритет (высокий/средний/низкий)
- Статус (ожидание/в работе/выполнено)
- Срок выполнения
- Связанная метрика

**Возможности**:
- Создание задач вручную
- Автогенерация рекомендаций
- Изменение статуса
- Удаление задач
- Фильтрация по статусу и приоритету

### Автоматическая генерация задач
**Анализирует**:
- Маржинальность < 10% → Оптимизация расходов
- CAC > 1000 → Оптимизация каналов привлечения
- Точка безубыточности не достигнута → Увеличение среднего чека

**Создает задачи с**:
- Приоритетом (на основе критичности)
- Описанием проблемы
- Связанной метрикой
- Рекомендуемыми действиями

## 9. Визуализация и графики

### Типы графиков

**Bar Charts** (столбчатые):
- Сравнение метрик по сценариям
- Сравнение с конкурентами
- Структура расходов

**Pie Charts** (круговые):
- Распределение расходов
- Структура выручки по продуктам
- Доли рынка

**Line Charts** (линейные):
- История изменений метрик
- Прогнозы трендов
- ROI по периодам

**Composed Charts** (комбинированные):
- Прогнозирование с доверительными интервалами
- Исторические данные + прогноз

**Radar Charts** (радарные):
- Конкурентный индекс
- Многомерное сравнение

### Интерактивность
- Tooltips с детальной информацией
- Hover эффекты
- Responsive дизайн
- Адаптация к мобильным устройствам

## 10. ROI и чувствительность

### ROI Calculator
**Входные параметры**:
- Начальные инвестиции
- Период анализа (месяцы)

**Расчеты**:
- ROI (%)
- Срок окупаемости (месяцы)
- Накопленный денежный поток
- Ежемесячная прибыль

**Сравнение**:
- По трем сценариям
- Графики накопленного cash flow
- Таблица метрик

### Sensitivity Analysis
**Анализ влияния изменений**:
- Выручки (±10%, ±20%)
- Постоянных расходов (±10%, ±20%)
- Переменных расходов (±10%, ±20%)
- Маркетинговых расходов (±10%, ±20%)

**Визуализация**:
- Tornado chart (торнадо-диаграмма)
- Ранжирование факторов по влиянию
- Количественная оценка чувствительности
